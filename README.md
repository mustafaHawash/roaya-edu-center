# Roaya-edu-center
Roaya Educational Center Project: a responsive educational center website built using HTML and Tailwind CSS.
---

## 📌 Features
- Responsive design for all devices
- Arabic language support
- Structured pages: Home & Courses
- Modern UI using Tailwind CSS
- Ready to integrate Dark Mode in future

---

## 🛠 Tech Stack
- HTML
- Tailwind CSS (via CDN)
- Font Awesome (Icons)
